## English

DeskPet is a desktop companion app for **macOS and Windows**, bringing your favorite pet to your desktop through transparent animations.

This repository is the public home for DeskPet downloads and user documentation. It does not contain the application's source code.

### Project status

DeskPet is in early development, with ongoing improvements to the user experience.

**No installers have been published in this repository yet.** Once a release is ready, its installers and release notes will be available on the [Releases](https://github.com/DannyYu2010/DeskPet-Downloads/releases) page, together with system requirements, installation instructions, and known issues.

### About DeskPet

DeskPet is designed to provide a quiet desktop companion experience:

- Import pet images or short videos.
- Configure everyday animations, sleep states, and custom actions.
- Drag your pet around the desktop while transparent areas let mouse clicks pass through.
- Keep pet assets and personal settings on your device.

The app is still evolving. Please refer to each release's notes for the features available in that version.
